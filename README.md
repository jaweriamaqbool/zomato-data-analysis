# 🍽️ Zomato Data Analysis

An exploratory data analysis project focused on understanding restaurant data from Zomato using Python, Pandas, NumPy, Matplotlib, and Seaborn.

The project explores the dataset through data cleaning, analysis, and visualization to identify patterns and relationships within the restaurant data.

## 📌 Project Overview

This project was created to practice the complete workflow of an exploratory data analysis (EDA) project — from loading and understanding raw data to cleaning, analyzing, and visualizing it.

The analysis focuses on questions such as:

* What does the dataset look like?
* What types of restaurants are present?
* How are restaurants distributed across different categories?
* What patterns can be observed in ratings and other restaurant attributes?
* What relationships can be identified through data visualization?

## 🛠️ Technologies & Libraries

## 🔎 Analysis Workflow

The project follows these general steps:

### 1. Data Loading

The Zomato dataset is loaded into a Pandas DataFrame for analysis.

### 2. Data Exploration

The dataset is examined to understand:

* Number of rows and columns
* Column names
* Data types
* Missing values
* Unique values
* Basic statistical information

### 3. Data Cleaning

The data is prepared for analysis by identifying and handling issues such as missing or inconsistent values where necessary.

### 4. Exploratory Data Analysis

Different Pandas operations are used to explore patterns and relationships within the dataset.

### 5. Data Visualization

Visualizations are created using Matplotlib and Seaborn to make patterns in the data easier to understand.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/jaweriamaqbool/zomato-data-analysis.git
```

### 2. Navigate to the project directory

```bash
cd zomato-data-analysis
```

### 3. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Open the notebooks

```bash
jupyter notebook
```

Then open either of the `.ipynb` files to explore the analysis.
